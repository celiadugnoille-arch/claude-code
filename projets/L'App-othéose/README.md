# L'App-othéose

L'application, élevée à son point d'incandescence.

**App** se glisse dans *apothéose* : le moment où l'ouvrage quitte
le métier et devient une forme nette, haute, définitive. Pas un
effet. Une densité.

```
L ' A P P — O T H É O S E
─────────────────────────
        haute définition
```
